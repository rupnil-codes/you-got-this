# you-got-this README

Get encouragements while coding to boost your motivation.

## Features

Adds a small status bar (with a heart!) on the bottom left that displays motivational quotes! Quotes change every 60 seconds

## Usage:

### Step 1: MARKETPLACE
Go to this [LINK](https://marketplace.visualstudio.com/items?itemName=rupnil-codes.you-got-this-rupnil) and install directly

### Step 2: .VSIX

Download the .vsix release from Github Releases and install it in your editor.
